# esg-report-analyzer

## Short project description

Retrieval-augmented generation (RAG) pipeline that ingests PDF reports from Tallink Grupp and 
Eesti Energia, answers predefined ESG-related questions using only document context, and outputs structured JSON with source citations and confidence levels.
